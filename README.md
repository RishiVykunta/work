# Personal Study Task Website

A personal study planner and focus timer built for daily preparation. It helps me plan tasks, track study time, build streaks, and stay motivated until my January 1 goal.

Live website: https://work-six-beryl.vercel.app/

## Features

- Name-based welcome screen with a personal greeting
- Local login/register flow so multiple people can use their own profile in the same browser
- Setup questions for name, aim, target days, and daily study target
- Daily study task planner with start time and target minutes
- Focus timer that keeps counting even when switching tabs
- Sticky mini timer with time left and `+5` / `-5` minute controls
- Completion popup with an appreciation message
- Study streak and best streak tracking
- January 1 countdown with progress indicator
- Study hours bar graph with days on the X axis and hours on the Y axis
- Motivational background and interactive visual cards
- Dark, responsive interface for desktop and mobile

## How To Run Locally

Open `index.html` directly in a browser.

No backend or install step is required. The website saves login profiles and study data in the browser using local storage.

## Files

- `index.html` - website structure
- `styles.css` - layout, dark theme, images, and animations
- `app.js` - tasks, timer, streaks, countdown, graph, and local storage
